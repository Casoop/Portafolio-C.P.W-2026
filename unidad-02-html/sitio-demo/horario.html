Horario y guia del curso.

Materiales del curso (con lista desordenada):

  • Visual studio code.
  • Cuenta de GitHub.
  • Cuaderno de bitácora.
  • Computadora con conexión a internet.

Como entregar una práctica (con lista ordenada):

  1. Traer los cambios con git pull.
  2. Crear la rama para la práctica con "git checkout -b" o "git switch -c" + "nombre-de-la-rama".
  3. Trabajar y hacer commits atómicos.
  4. Subir la rama con git push.
  5. Abrir un pull request en GitHub.
  6. Revisar y fusionar el pull request.
  7. Volverse a la rama principal (main).
  8. Eliminar la rama de la práctica con git branch -d "nombre-de-la-rama".

Glosario Git (con listas descriptivas):

Commit
Instantánea permanete del proyecto en un momento dado.
Rama
Línea de trabajo paralela que no afecta a main.
Pull
Solicitud de revisión para incorporar una rama.

Temario de la unidad (con lista anidada):

  • Estructura de un documento web:
    • DOCTYPE y HTML.
    • Head y metadatos.
  • Contenido:
    • Texto y enlaces.
    • Listas y tablas.
